1장 들어가며 — 코딩 에이전트 하네스란

이 책은 OpenCode V2(v2.3.0, 2026년 11월 13일 출시)를 "어떻게 쓰는가"가 아니라 "왜 이렇게 만들어졌는가"의 관점에서 해부합니다. 1장에서는 책 전체를 꿰는 개념인 에이전트 하네스를 정의하고, 이 책을 읽는 방법을 안내합니다.

1.1 LLM은 판단하고, 하네스는 행동한다

LLM은 텍스트를 받아 텍스트를 내놓을 뿐입니다. 파일을 읽지도, 명령을 실행하지도, 어제 한 일을 기억하지도 못합니다. "로그인 오류를 찾아 고치고 테스트까지 돌려 줘"라는 요청을 실제 작업으로 바꾸려면 모델 바깥에서 다음 일을 해 줄 프로그램이 필요합니다.

  • 모델이 볼 컨텍스트(대화, 규칙, 도구 설명, 환경)를 조립합니다.
  • 모델이 "grep을 실행하라"고 하면 권한을 확인하고 실제로 실행합니다.
  • 결과를 다시 모델에게 보여 주고, 끝날 때까지 반복합니다.
  • 이 모든 과정을 기록하고, 끊기면 이어서 하고, 잘못되면 되돌립니다.

이 프로그램을 하네스(harness)라고 부릅니다. 말에 채우는 마구처럼, 모델의 힘을 실제 일로 연결하는 장치입니다. OpenCode의 기본 시스템 프롬프트도 스스로를 "a coding agent harness"라고 소개합니다.

1.3 OpenCode V2를 한 문장으로

한 문장 요약 OpenCode V2는 SQLite 이벤트 로그 위에서, 세션마다 하나의 실행 파이버가 inbox에서 입력을 승격하며 스텝마다 이력을 다시 읽어 LLM을 한 번씩 호출하고, 그 결과를 SSE로 여러 클라이언트에 뿌리는, Effect로 쓰인 백그라운드 서버입니다.
