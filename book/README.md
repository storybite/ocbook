# OpenCode V2 해부 — 책 + 책 Q&A 챗봇

형식은 `ii/ii1/book`(『그래프RAG 실무』)의 책 챗봇을 따릅니다. 본문의 문단·표·그림·코드 블록을 클릭하면 💬 팝업이 열리고, 클릭한 위치와 앞뒤 문단을 맥락으로 책에 질문합니다.
- **절 제목**(`2.2 …` 같은 `<h2>`)을 클릭하면 그 **절 전체**를 맥락으로 묻습니다("이 절을 요약해 줘" 등).
  - 절 본문은 브라우저가 보내지 않습니다. 서버가 색인의 절 파일(`bookbot/corpus/<절id>.md`)을 직접 읽어 넣습니다(최대 24,000자).
  - 챗 창 위에는 "📚 이 절 전체에 대해 묻습니다"로 표시되고, 대화를 나눈 절 제목 옆에 💬가 붙습니다.

## 준비
```bash
pip install -r book/requirements.txt
# (선택) book/.env 에 FIRECRAWL_API_KEY 가 있으면 웹 검색·페이지 읽기 도구를 씀
```
챗봇은 Claude Agent SDK(`claude-agent-sdk`)로 모델을 부르며, SDK가 띄우는 `claude` CLI의 로그인(**Claude Code 구독**)을 씁니다. 미리 `claude`에서 `/login` 해 두세요.
- 모델은 `CHAT_MODEL`(기본 `claude-opus-5-5`), 생각 깊이는 `CHAT_REASONING_EFFORT`(기본 `medium`), 포트는 `CHAT_PORT`(기본 `8771`)로 정합니다.
- `ANTHROPIC_API_KEY`·`ANTHROPIC_AUTH_TOKEN`이 환경에 있으면 API 과금으로 넘어가므로 서버가 시작할 때 무시합니다.
- Claude Code의 내장 도구와 프로젝트 설정은 끄고, `read`(+선택 `web_search`·`web_fetch`)만 in-process MCP(`mcp__book__*`)로 줍니다.
- 표시되는 비용은 SDK가 알려 주는 **API 환산 금액**이며 실제 청구는 없습니다(구독 사용량에서 차감).

## 모델 선택 (Claude · Codex)
형식은 `book/oc1/chatbot`의 모델 선택을 따릅니다.
- 챗 창 제목줄의 모델 목록에서 답할 모델을 고릅니다. 고른 모델은 브라우저에 기억됩니다.
- Claude 모델은 Claude Agent SDK로 부르고, Codex 모델은 `codex exec --json`으로 부릅니다. Codex 모델 목록은 `~/.codex/models_cache.json`에서 읽으므로, Codex CLI가 설치·로그인되어 있어야 목록에 나옵니다. Codex는 ChatGPT 로그인을 씁니다.
- Codex는 사용자 설정(`~/.codex/config.toml`의 플러그인·MCP)을 무시하고(`--ignore-user-config`), 셸은 읽기 전용 샌드박스로 띄웁니다.
  - 책 도구(`read` 등)는 서버의 `/mcp/<token>`으로 붙이며, 이 주소는 요청 하나 동안만 유효합니다.
- 대화 맥락(요약·최근 턴)은 매 요청에 붙여 보냅니다. 그래서 대화 도중에 Claude ↔ Codex로 바꿔도 대화가 이어집니다.
- Codex는 비용 금액을 알려 주지 않아 토큰 수만 표시합니다.
- 실행 파일 위치는 `CODEX_BIN`으로 바꿀 수 있습니다. 생각 깊이는 `CHAT_REASONING_EFFORT`를 같이 씁니다(`max`는 Codex에서 `xhigh`로 바뀝니다).

## 이미지 붙이기
- 챗 창에 이미지를 붙여 질문할 수 있습니다. 화면 캡처, 다이어그램, 오류 메시지 사진 등을 모델이 직접 봅니다.
- 붙이는 방법: 입력창에서 **Ctrl+V**(클립보드의 이미지), 챗 창으로 **끌어 놓기**, 또는 입력창 왼쪽 **📎** 버튼.
  - 붙인 이미지는 입력창 위에 미리 보기로 나오고, ×로 뺄 수 있습니다.
  - 질문 하나에 4장까지 붙입니다. 글을 비우고 보내면 "붙인 이미지를 보고 설명해 주세요."로 보냅니다.
- 형식과 크기:
  - PNG·JPEG·WebP·GIF를 받습니다.
  - 긴 변이 1568px를 넘거나 3.5MB를 넘으면 브라우저가 줄여서 보냅니다. 화면 캡처(PNG)는 글자가 또렷하도록 되도록 PNG로 유지합니다.
  - 서버는 base64·파일 머리(매직 바이트)·5MB 제한을 다시 확인합니다.
- 모델에 전달하는 방법:
  - Claude: SDK의 스트리밍 입력으로 이미지 블록과 글을 함께 보냅니다.
  - Codex: `codex exec -i <파일>`로 보냅니다.
  - 이미지는 **그 질문에만** 보내고, 다음 질문의 대화 기록에는 "(이미지 n장 첨부)"만 남깁니다.
- 저장: `bookbot/uploads/<대화 id>/`에 저장해, 지난 대화를 다시 열면 썸네일이 보입니다(클릭하면 크게). 대화를 삭제하면 이미지도 함께 지웁니다.

## OpenCode 소스 참조 (읽기 전용)
- 챗봇은 책이 분석한 소스를 직접 찾아 읽을 수 있습니다.
  - V2 = OpenCode 2.3.0: `D:\workspace\cc\opencode\v2\repo`
  - V1 = OpenCode 1.19.5: `D:\workspace\cc\opencode\v1\repo`
  - 위치는 환경 변수 `OPENCODE_SRC`(기본 `D:\workspace\cc\opencode`)로 바꿉니다.
- 도구(Claude·Codex 공통, 늘 켜짐):
  - `opencode_search(version, pattern, path?)`: `git grep -E`로 추적 파일을 검색합니다. 파일당 5줄, 전체 60줄까지 보여 줍니다.
  - `opencode_read(version, path, start?, end?)`: 파일을 줄 번호와 함께 읽습니다. 한 번에 400줄까지이며, 폴더 경로면 목록을 보여 줍니다.
- 소스를 보는 경우:
  - 사용자가 소스·구현·코드 위치를 묻거나 확인을 요청할 때.
  - 책에 없는 구현 세부가 필요하거나, 책 설명이 코드와 맞는지 따져야 할 때.
  - 책 수정 중에 코드를 인용할 때.
- 답변에는 `v2 packages/core/src/session/runner/llm.ts:216`처럼 버전·경로·줄 번호로 출처를 밝힙니다. 직접 본 코드만 인용합니다.
- 두 저장소 밖으로 나가는 경로, `.git`, `.env`·키 파일은 거부합니다. 읽기 전용이며 소스를 고치는 도구는 없습니다.
- 화면의 탐색 기록에는 소스 검색·읽기가 🧩로 표시됩니다(책 읽기는 📖).
- 도구 호출 한도(`CHAT_MAX_TOOL_CALLS`)는 책 읽기·소스·수정을 합쳐 16회입니다.

## 책 수정 (채팅으로 원고 고치기)
- 책 수정은 챗 창 제목줄의 **[✏️ 책 수정]** 을 켰을 때만 됩니다. 켜면 버튼과 입력창이 초록으로 바뀌고, 그동안 보낸 요청 말풍선에 `✏️ 수정` 표시가 붙습니다.
  - 단축키: 입력창에서 **Ctrl+Enter**(맥은 Cmd+Enter)로 보내면 [✏️ 책 수정]을 켜고 그 요청을 책 수정 요청으로 바로 보냅니다. 입력창이 비어 있으면 모드만 켭니다. 그냥 Enter는 질문으로 보냅니다.
  - 꺼져 있으면 서버가 그 요청에 수정 도구(`read_source`·`replace_text`)를 아예 주지 않습니다. 실행기와 Codex용 MCP 주소도 그 요청에서는 수정 도구를 거절합니다.
  - 꺼진 상태에서 고쳐 달라고 하면 모델은 고칠 내용만 제안하고 [✏️ 책 수정]을 켜라고 안내합니다.
  - 수정 요청 하나로 원고가 실제로 고쳐지면 그 답변이 끝날 때 저절로 꺼집니다("수정을 마쳐 [책 수정] 모드를 껐습니다" 안내). 모델이 고치지 않고 되묻기만 했으면 켠 채로 두어 이어서 답할 수 있습니다.
  - 켠 상태는 저장하지 않으므로 페이지를 새로 열면 늘 꺼진 상태로 시작합니다.
- 켠 상태에서 고칠 블록을 클릭하고 "이 문단을 더 쉽게 고쳐 줘", "이 표에 V1 열을 추가해"처럼 **고치라고** 쓰면 모델이 원고를 직접 고칩니다. 켜져 있어도 질문에는 고치지 않습니다.
- 모델의 절차:
  1. `read_source("<절id>")`로 원고 `src/chNN.html`의 그 절 HTML을 읽습니다.
  2. `replace_text(id, old, new)`로 고칩니다. `old`는 파일에서 한 번만 나와야 합니다.
  3. 서버가 `src/build.py`와 `bookbot/build_index.py`를 다시 돌려 책과 색인에 반영합니다.
- 다음 경우에는 서버가 고치지 않습니다.
  - 기존 `id`가 사라지는 수정. 링크가 깨지기 때문입니다.
  - 스크립트·이벤트 속성·외부 리소스 태그를 넣는 수정.
  - 고친 뒤 빌드가 실패하는 수정. 이때는 원래대로 되돌립니다.
- 원고의 줄바꿈(CRLF·LF)은 파일마다 원래대로 유지합니다.
- 고치면 답변 아래에 수정 카드가 나옵니다.
  - 원고 변경 보기: 지운 부분과 넣은 부분을 diff로 보여 줍니다.
  - [고친 곳 보기]: 고친 곳으로 이동해 잠깐 강조합니다.
  - [되돌리기]: 고치기 전으로 되돌립니다.
  - 책 화면은 새로고침 없이 그 장만 바로 바뀝니다.
- 수정 기록은 `bookbot/edits.jsonl`에 남습니다(수정 1건 = 1줄, `old`·`new` 원문 포함). 되돌리기는 이 기록으로 원고의 `new`를 `old`로 바꾸는 것입니다. 그 뒤 같은 곳을 또 고쳤으면 되돌리기를 거절합니다.
- git 저장소가 아니므로 이 기록과 되돌리기가 유일한 이력입니다. 원고를 크게 고치기 전에는 `src/`를 따로 백업해 두세요.

## 답변 중지 (Esc)
- 답을 만드는 중에 **Esc**를 누르면 생성을 멈춥니다. 상태 줄에 `Esc 중지` 표시가 있는 동안이 그때입니다. 이때 Esc는 창을 닫지 않고, 멈춘 뒤에 한 번 더 누르면 창이 닫힙니다.
- **Ctrl+N**(맥은 Cmd+N)은 [새 대화]와 같습니다. 답을 만드는 중이면 먼저 멈추고(멈춘 턴은 앞 대화에 저장), 입력 중인 글은 그대로 둡니다. 단 일반 브라우저 탭에서는 브라우저가 이 키를 '새 창'으로 먼저 가져가 페이지까지 오지 않습니다. `chrome --app=http://127.0.0.1:8771/`처럼 앱 창으로 열면 동작합니다.
- 화면은 Esc를 누른 그 자리에서 끝나고 바로 입력할 수 있습니다. 서버의 마무리(모델 프로세스 정리, 대화 저장, 사용량)는 뒤에서 받아 기록만 맞춥니다. 화면에 닿기 전에 끊긴 마지막 조각이 있으면 그때 답을 서버 쪽 내용으로 다시 그립니다.
- 그 마무리가 오기 전에 다음 질문을 보내면 상태 줄에 `앞 답변 정리 중`이 뜨고, 서버가 앞 턴을 저장해 돌려준 기록을 받은 뒤에 보냅니다. 보통 1초 안쪽입니다.
- 브라우저가 질문마다 만든 `request_id`로 `/api/chat/stop`을 부르면 서버가 그 질문을 멈춥니다.
  - Claude: CLI에 interrupt를 보냅니다. CLI가 턴을 바로 멈추고 결과를 낸 뒤 1초 안팎에 끝나며, 그 결과의 사용량도 기록합니다. interrupt 후 3초 안에 안 끝나면 취소합니다.
  - Codex: `codex exec` 프로세스를 바로 끝냅니다. Codex는 턴이 끝나야 사용량을 알려 주므로 사용량은 남지 않습니다.
- 그때까지 쓴 답은 `⏹ 중지함` 표시와 함께 남고, 대화 이력에도 저장됩니다(`"stopped": true`). 다음 질문의 모델에게는 "사용자가 답변 도중 중지함"이 함께 전달되므로 "계속해"처럼 이어서 물을 수 있습니다.
- 중지 전에 책을 고쳤다면 수정 카드가 그대로 남아 되돌릴 수 있고, [✏️ 책 수정]은 꺼집니다.
- 서버의 마무리가 8초 안에 오지 않으면 기다리기를 그만두고 연결을 끊습니다(서버 쪽 정리와 저장은 그대로 진행). 이때 다음 질문에는 앞 턴이 빠질 수 있습니다.

## 빌드와 실행
```bash
python book/src/build.py              # 원고(src/ch*.html) + 챗봇 화면(src/_chat.html) → opencode-v2.html
python book/bookbot/build_index.py    # 책 → 챗봇 색인 bookbot/corpus/ (index.md + 장·절별 .md)
python book/server.py                 # http://127.0.0.1:8771/
```
원고를 고치면 두 빌드를 모두 다시 실행하세요(색인이 책보다 오래되면 서버가 시작할 때 경고합니다). `opencode-v2.html`을 파일로 직접 열면 책은 읽히지만 챗봇은 동작하지 않습니다.

주의: 기록 API(`/api/usage`, `/api/conversations`)와 책 수정(채팅·`/api/edits`)에는 인증이 없습니다. 127.0.0.1 전용으로 두고 외부에 공개하지 마세요. 공개하면 누구나 원고를 고칠 수 있습니다.

## 구조
| 경로 | 역할 |
|---|---|
| `src/` · `src/build.py` | 책 원고(장별 조각)·템플릿과 조립 스크립트 |
| `src/_chat.html` | 책에 묻기 팝업·대화 이력·토큰/비용 패널(스타일+스크립트) |
| `bookbot/build_index.py` | 책 HTML을 `<h2 id>` 기준 절 단위 마크다운과 색인으로 나눔 |
| `bookbot/corpus/` | 색인(`index.md`, 시스템 프롬프트에 미리 넣음)과 절 파일(`read` 도구로 읽음) |
| `bookbot/prompts/` | Claude 에 넘기는 시스템 프롬프트 파일(내용 해시 이름). Windows 명령줄 32,767자 한도 때문에 `--system-prompt` 대신 `--system-prompt-file` 로 넘긴다. 지워도 다음 질문 때 다시 생김 |
| `bookbot/conversations/` · `usage.jsonl` | 대화 이력(대화 1건 = 1파일), 질문별 사용량 누적 |
| `bookbot/edits.jsonl` | 채팅으로 고친 책 수정 기록(되돌리기에 씀) |
| `bookbot/uploads/` | 질문에 붙인 이미지(대화별 폴더, 대화를 지우면 함께 삭제) |
| `server.py` | 책 HTML과 챗봇 API(SSE 스트리밍, 대화 압축, 도구 호출 한도·누적 예산, 책 수정·되돌리기) |
